# Hướng Dẫn Nhanh / Quick Start

## Tiếng Việt

### Cách nhanh nhất để chạy website:

1. Mở Terminal/Command Prompt
2. Di chuyển vào thư mục dự án:
   ```bash
   cd hongocphuong.github.io
   ```
3. Chạy một trong các lệnh sau:
   ```bash
   # Python (Khuyến nghị - đơn giản nhất)
   python3 -m http.server 8000
   
   # Hoặc Node.js
   npx serve
   ```
4. Mở trình duyệt và truy cập: http://localhost:8000

📖 Xem [README.md](README.md) để biết thêm chi tiết và các phương pháp khác.

## English

### Quickest way to run the website:

1. Open Terminal/Command Prompt
2. Navigate to the project directory:
   ```bash
   cd hongocphuong.github.io
   ```
3. Run one of these commands:
   ```bash
   # Python (Recommended - simplest)
   python3 -m http.server 8000
   
   # Or Node.js
   npx serve
   ```
4. Open your browser and visit: http://localhost:8000
